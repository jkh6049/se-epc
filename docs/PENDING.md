## 1. 사업지원·영업 확장 반영 순서

1. `git checkout feat/v57-pipeline && git merge main` (main 의 최신 변경을 먼저 받음)
2. 사업지원 엑셀 기준으로 개요(사업 개요·인수인계) 항목 보완 → 로컬 확인
3. 개인 계정을 아직 넣지 않을 거면 계정 관련 코드를 빼고 합칠 것 (아래 2 참고)
4. main 에 합친 뒤 배포할 때 함께:
   - `node scripts/patch.mjs https://se-epc.com data/patch/2611-v57-handoff.json --apply` (기존 착공 현장 4곳 인계 완료 처리)
   - 운영에서 동해12호·반도코리아 개요 [엑셀에서 불러오기]
5. 홈 '사업부 현황'(legacy/mgr.js)은 v57 기능이 있으면 사업 흐름·구간을 자동으로 실제 값으로 보여줌 (main 은 빈칸 틀)

## 2. 개인 계정 반영 시

- 서버: `worker/auth.ts`(로그인·내 계정 화면·쿠키) · `worker/index.ts`(users 표·/api/auth/*·/api/me·/api/account·관리 API·웹소켓 작성자) · `worker/admin.ts`(0. 계정 카드)
- 화면: `legacy/index.html` v59e 블록 (상단 이름 메뉴·내 정보)
- 배포 후 운영 `/admin` 에서 관리자 계정부터 발급 (처음엔 비상용 관리자 비밀번호로 진입) → 직원 계정 발급 → 전환 기간 뒤 [공용 로그인 종료]
- 검증 스크립트: 로그인·비밀번호 규칙·쿠키 무효화·작성자 위조 차단 등 35개 항목 (세션 기록 참고)
- 관리자 비밀번호는 코드에 넣지 않음 (wrangler secret ADMIN_PASSWORD). 개인 계정 도입 때 더 긴 값으로 교체 권장
